# TPO-Fundamentos-de-Inform-tica---UADE-2026
Este código permite cargar pokémons en una base de datos en forma de matriz, anotando sus nombres, tipos (entre los disponibles), victorias, puntos de combate,
nivel, estado (entre los disponibles) y nombre de su entrenador, no permite agregar dos pokémons con el mismo nombre exacto y tampoco cargarlos sin nombre, el
número de victoria no tiene límite al igual que los puntos de combate, el nivel puede llegar hasta 100 como límite, hay una limitación al intentar crear el pokémon
con valores aleatorios de puntos de combate y victorias, ya que en caso de agregarse de forma aleatoria se limitan hasta 6000 y 5000 respectivamente. Al querer modificar
los datos de un pokémon lo que hace es eliminar de la matriz el pokémon elegido para agregarlo nuevamente con los nuevos datos ingresados. Solo permite eliminar un
pokémon si el mismo está en estado liberado, de no haber ningún pokémon con esta característica solo imprime un mensaje informando que no hay pokémons que cumplan con
lo necesario para ser eliminados.
